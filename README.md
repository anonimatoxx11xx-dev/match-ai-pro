# Match AI Pro

Flutter Android app per analisi calcistica.

Il workflow GitHub Actions compila una release APK chiamata **MatchAIPro.apk**.

Funzioni UI:
- Partite della giornata
- Tiri e tiri in porta
- Corner
- Falli
- Cartellini
- Rimesse
- Parate
- Scheda partita interattiva
- Proposte IA
- AI Center

I valori attualmente inclusi nell'interfaccia sono dimostrativi e non vengono presentati come dati live. Il prossimo layer collegherà un provider statistico reale tramite API/backend.
